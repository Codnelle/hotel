# Hero video

Add `dawn.mp4` (H.264), and optionally `dawn.webm`, here. Keep it under 3 MB: 8–12 s loop, 1280px wide, no audio track.
Until it exists, the hero shows the Mist-to-Teesta gradient poster (or `/images/hero-poster.jpg` if you add one).
The video is skipped on Save-Data or 2G/3G connections, and with reduced motion turned on.
